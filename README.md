# 🧍 Smart Posture Correction System

## 📌 Overview
The **Smart Posture Correction System** is a real-time computer vision application that detects and analyzes human posture using a webcam. It provides instant feedback to help users maintain proper posture and reduce physical strain.

This project leverages **OpenCV** and **MediaPipe Pose** to track body landmarks and evaluate posture dynamically.

---

## 🚀 Features
- 🎥 Real-time posture detection using webcam  
- 🧠 Human pose estimation with MediaPipe  
- ⚡ Instant feedback: *Correct / Incorrect posture*  
- 📊 Landmark-based posture analysis  
- 🖥 Simple interactive UI using Streamlit (optional)  
- ♿ Can be extended for accessibility applications  

---

## 🛠 Tech Stack
- **Programming Language:** Python  
- **Libraries:** OpenCV, MediaPipe, NumPy  
- **Framework (optional):** Streamlit  
- **Tools:** Jupyter Notebook, Git, GitHub  

---

## 🧠 How It Works
1. Captures video from webcam  
2. Uses MediaPipe to detect body landmarks  
3. Analyzes key points (neck, shoulders, back alignment)  
4. Evaluates posture based on predefined conditions  
5. Displays real-time feedback on screen
